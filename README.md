# JoAi

JoAi plugin — board callbacks and hosted MCP for apps and agents.

[Open app page](https://joai.ai/en/apps/joai) · [Browse all apps](https://joai.ai/apps)

## Works With

- ChatGPT
- Claude
- Codex
- Cursor
- Other MCP clients

## Install

### Claude

```bash
/plugin marketplace add JoAiHQ/claude-plugins
/plugin install joai@joai-claude-plugins
/plugin install joai@joai-claude-plugins
```

### Codex

Install this app from the official JoAi Codex marketplace in Codex.

`joai`

If your Codex build only supports MCP registration, use the MCP endpoint below as a manual fallback.

### Cursor

Use the [Cursor install link](cursor://anysphere.cursor-deeplink/mcp/install?name=joai&config=eyJ1cmwiOiJodHRwczovL2NvcnRleC5qb2FpLmFpL21jcC9hcHBzL2pvYWkifQ==) to install directly.



### ChatGPT

Paste the MCP URL in ChatGPT settings:

```
https://cortex.joai.ai/mcp/apps/joai
```
